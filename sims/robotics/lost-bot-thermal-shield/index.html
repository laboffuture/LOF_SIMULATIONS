LOST BOT COOLING SYSTEM

Automatic processor cooling & smoke safety control

  1. Trigger a temperature condition with the quick buttons, or drag the slider for fine control. Watch the sensor reading move and the controller pick a fan speed automatically — nothing here is manual.
  2. Read the Active Controller Rule banner above the processor cooler view. It always states, in plain words, exactly which threshold rule just fired.
  3. Click Smoke Detected at any temperature — even a cold, safe one — and watch smoke safety override the temperature logic and force ventilation on.
  4. Push temperature into Above 40°C while smoke is still on to see the combined heat + smoke emergency — the highest-priority safety mode.
  5. Try Blocked on the ventilation path — the fan still runs, it just can't move air, so cooling and smoke clearing both slow down.
  6. Use Reset System to return everything to a safe baseline, or run the Guided Mission for a scripted walk through the full cooling sequence.
