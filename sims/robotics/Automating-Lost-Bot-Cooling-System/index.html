AUTOMATING LOST BOT'S COOLING SYSTEM

  1. Press Start under the cooler view to switch the controller on. Pause freezes it.
  2. Set the Internal Temperature Sensor. The quick buttons — Below 30°C, 30°C–35°C, 35°C–40°C and Above 40°C — jump straight into a zone. The Temperature slider (15°C–48°C) gives fine control. The controller picks the fan speed by itself — nothing here is manual.
  3. Read the Active Controller Rule banner above the cooler view. It says in plain words which rule just fired: below 30°C the fan is OFF, 30–35°C LOW, 35–40°C MEDIUM, above 40°C HIGH.
  4. Click Smoke Detected at any temperature — even a cold, safe one — and watch smoke safety override the temperature rule and turn ventilation on. Air Safe clears it.
  5. Use Smoke Intensity (0–100%) to set how much smoke there is, and Detection Threshold (1–50%) to set how much the sensor needs before it reacts. A higher threshold makes it less twitchy; a lower one catches fainter traces.
  6. Push the temperature Above 40°C while smoke is on to see the combined heat + smoke emergency — the highest-priority safety mode.
  7. Try Blocked on the Ventilation Path. The fan still runs, but it can't move air, so cooling and smoke clearing both slow down. Clear opens it again.
  8. Watch Cooling & Safety Status: Temperature, Temp Zone, Smoke Status, Ventilation, Fan Speed and System Health. Under Power & Airflow, check the Battery, the Smoke Concentration, the heat trend and the time spent in danger.
  9. Read System Feedback for a short message about what just happened.
  10. Press Reset System to return to a safe start, or Run Guided Mission for a step-by-step walk through the whole cooling sequence.
  • Temperature sensing: a temperature sensor watches the robot's internal heat all the time.
  • Smoke sensing: a smoke sensor detects harmful smoke in the air.
  • Automatic fan control: the fan speed changes by itself when the temperature crosses set thresholds.
  • Fan off when cool: the fan stays OFF below 30°C on purpose — it saves power when cooling isn't needed.
  • Speed in steps: as the temperature rises, the fan steps up from Low to Medium to High.
  • Safety first: smoke detection overrides the normal temperature rule, because getting smoke out matters more.
  • Two dangers at once: heat and smoke together trigger their own top-priority emergency mode.
  • Threshold logic: the controller uses thresholds on two sensor inputs to choose exactly one safety response.
  • Airflow matters: a blocked air path slows recovery even with the fan running.
