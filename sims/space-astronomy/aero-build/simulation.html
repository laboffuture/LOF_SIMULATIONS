Aero Build Flight Manual

Motor-Powered Rocket Design & Stability

Everything the simulation needs comes from the design you build and the motor designation you type in — no outside data lookups.

  1. Design: Pick a nose shape, size the body, add fins, and drag the green CG marker along the rocket. The stability gauge reacts instantly.
  2. Static Margin: (CP − CG) / diameter, in body-diameters ("calibers"). Below 1 the rocket tumbles. 1–2 is the band you want. Above 2 it is over-stable — it snaps into any crosswind and weathercocks badly, so it flies a long way downwind instead of up.
  3. Fins: Span is by far the strongest control — the fin's effect goes as span squared. Sweep buys margin almost free. Fin count is shown honestly in the rear view, and every fin you add is also drag.
  4. Drag: The Cd shown in the outputs is built up from the nose shape, skin friction along the body, the fins, and base drag — so a longer body or bigger fins really do cost you altitude.
  5. Staging: A booster fires first and is dropped at burnout, so the rest of the climb carries less mass. It only pays if the booster burns hard while attached — watch the dashed orange trace showing where the spent booster falls.
  6. Recovery: The parachute opens on the motor's real ejection delay (or, in Dual Deploy, a drogue at apogee and the main chute lower down). Safe descent is 4.5–6 m/s — the panel predicts it before you fly.
