Ascent Lab

A pressure-launched model rocket. Build it, launch it, read the same numbers a real flight review uses.

This is a compressed-air / water rocket — the kind you build in a kit. It flies straight up a few tens of metres, so the goals are target altitude bands, not orbit. Every launch is a fresh flight; the old path stays as a faded trace so you can compare.

  1. Pick a nose cone, body length, fins, and a launch pressure on the right.
  2. Press LAUNCH. Watch the altitude, velocity, drag, and stability update live.
  3. Try the scenarios up top: Open Field Test (big target, no wind), Crosswind Range (wind, fins matter), Precision Pad (small target, everything matters).
  4. Remove the fins and launch: the rocket goes unstable and tumbles — that's the stability margin dropping below 1.
  5. Flip Show the math to see the boost, coast, and stability equations, each with every number plugged in.

The physics (simplified on purpose)

Boost is a single impulse J = k·P·V, giving burnout speed v₀ = J/m — the same way real motors are rated by total impulse. Coast uses the exact closed-form solution for vertical flight against v² drag. Stability uses the model-rocket margin SM = (Xcp−Xcg)/d in calibers.

Real missions

ISRO PSLV: India's workhorse rocket separates into stages, dropping empty mass so the climb keeps accelerating — a real version of "lighter rockets go higher."

NASA sounding rockets: sub-orbital science rockets that, like this one, go up and come straight back down — used to carry experiments briefly above the atmosphere.

Note: the impulse constant k must be calibrated to your real launcher hardware; nose-cone drag values here are standard approximations until measured.
